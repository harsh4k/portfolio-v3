# Web PWA

The live website **is** the PWA. Source of truth:

- App: `harshit-portfolio/`
- Production output: `harshit-portfolio/dist/` (also mirrored to repo `dist/` on build)

Do not duplicate the site here. Install and caching live in:

- `harshit-portfolio/public/site.webmanifest`
- `harshit-portfolio/public/sw.js`
- `harshit-portfolio/public/offline.html`
- `harshit-portfolio/src/scripts/pwa.js`

See `docs/NOTHING-PHONE-4B.md` for install steps on a Nothing Phone (4b).
